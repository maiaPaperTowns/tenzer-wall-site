Original files are retained unmodified. Browser canvas crops and masks isolate details for animation; original inscriptions remain in the source files. Flower expansion, bird movement, sunlight, and painting reveals are code-driven. The canvas background is a plain CSS color. Rainbow, rain, and thunder are temporarily unavailable while awaiting approved replacement assets. Aoyagi Kouzan remains the existing typeface.

Old artwork is removed from the current published tree, not from historical Git commits. History is retained for recovery.
